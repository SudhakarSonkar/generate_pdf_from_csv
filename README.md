# 📘 PDF Notebook Generator

This Python project generates a **ruled PDF notebook** from a CSV file of topics.  
Each topic gets multiple pages with:
- A **header** showing the topic name  
- **Horizontal ruled lines** (like a notebook)  
- A **footer** repeating the topic name  

The number of pages per topic is taken from the CSV.

---

## 🚀 Features
- Automatic PDF creation from topics
- Custom ruled lines
- Dynamic number of pages
- Headers and footers per topic
- Supports multiple subjects
